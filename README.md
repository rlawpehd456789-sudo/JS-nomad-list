# JS-nomad-list

디지털 노마드를 위한 전 세계 도시 정보를 제공하는 Next.js 웹 애플리케이션입니다.

## 기술 스택

- Next.js 16.0.7 (App Router)
- React 19.2.0
- TypeScript 5
- Tailwind CSS 4.1.9
- shadcn/ui

## 주요 기능

- 전 세계 도시 정보 제공
- 대륙별 필터링
- 도시별 생활비, 인터넷 속도, 날씨 정보
- 반응형 디자인
- 다크모드 지원

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

## 프로젝트 구조

```
nomad-list-korea/
```
